# 率土之滨 视觉特征模板库说明 (2025~2026 征服赛季)

## 现代化视觉体系架构说明
在旧版外挂/脚本时代，常使用固定裁剪的小 PNG 模板（如早期 AutoStzb 中的 `attack_template.png`、`defense_template.png`、`condinate.png`）。
但在 2025~2026 现版本网易《率土之滨》中：
1. **官方 UI 材质与赛季主题频繁更迭**：木纹/赤壁/雪景/周年庆皮肤会导致小图像素差异过大，传统 `matchTemplate` 极易失效报错；
2. **分辨率与 DPI 畸变**：全面屏（20:9, 19.5:9）会导致固定像素切片失真。

### 现代化解决方案：【语义 OCR + 动态几何双引擎】
1. **语义按键定位 (`StzbUiMatcher`)**：
   - 优先通过本地离线 RapidOCR 识别文字（如“出征”、“扫荡”、“驻守”、“屯田”、“查看守军”、“确定”）；
   - 无论官方怎么更换按钮皮肤、边框花纹，只要中文字符不变，识别率 100%；
   - 配合高斯离散算法计算安全点击坐标，彻底消除固定像素点击导致的封号风险。
2. **非文字图形动态识别**：
   - **深夜敌袭红线雷达 (`RaidRadarDetector`)**：OpenCV HSV 双区间纯红掩膜 + 霍夫变换提取行军向量，并回溯敌军跳板要塞（决策 C）；
   - **土地免战罩与倒计时 (`TileStatusDetector`)**：HSV 提取金色免战罩外廓弧线 + 局部高速 OCR 提取数字倒计时；
   - **部队 2026 赛季士气与卡秒 (`TroopStatusDetector`)**：识别 120 满士气增益，毫秒级推算攻城集火出征时刻。
3. **动态模板加载 (`OpenCvMatcher`)**：
   - 支持在当前目录动态放置扩展模板，系统会自动枚举加载进显存，无需硬编码代码。

## `stzb/seeds/`：随包按键模板种子（与上面那段判断不冲突，这里说清边界）

上面"传统小 PNG 极易失效"的判断针对的是**旧脚本把模板当唯一手段**。这里的种子不是那个用法：

- 它是**通道 B 的兜底**，服务的是"OCR 引擎不可用"的默认构建（native 空桩）——那种状态下
  没有种子就只剩手动登记一条路。OCR 可用时优先走 OCR，改皮肤不慌。
- 种子按**画布坐标**（高恒 720）裁剪，跨机型由 `CoordinateTransformer` 按高归一吸收分辨率差。
- 每一张都过了 `tools/gen_button_seeds.py` 的五段验收（自检回搜 / 跨帧迁移 / 46+ 帧不误命中 /
  与包内文件逐像素对账），清单在 `tools/button_seeds.json`。**美术改版后种子会失配**，
  失配的表现是匹配不上（返回 null），不是点错位置——这是验收器强制"宁可找不到也不乱认"的结果。
- 端侧读取与优先级（本机登记 > 随包种子）的权威说明在 `service/ButtonTemplateStore.kt` 文件头。
