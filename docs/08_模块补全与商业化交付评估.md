## 二、设计红线：新增能力绝不能削弱既有安全

这是本轮最重要的一条原则，两处接线都按它设计：

**1. 夜战哨兵的 YOLO 只"提高"可信度，绝不下调等级**

```
OpenCV 雷达判定威胁 ──┬── YOLO 也检出 → 记为「双通道确认」
                      └── YOLO 未检出 → **等级不下调**，仅记为「单通道命中」
```

理由：视觉模型存在**漏检**。若用"视觉没检出"去下调等级，漏检一次就等于撤掉了
60 秒秒回保护——而那正是这个功能存在的全部意义。**宁可多一次不必要的撤退，
也绝不能漏掉一次真实偷家。**

**2. 屯田的地块复核只提示，不做闸门**

真实风险是"点击点偏了 → 对着空地点了屯田"浪费 3 策令。
但用它做硬闸门时，一次漏检就会让屯田功能整体不可用——那比浪费 3 令严重得多。

**3. 30 秒限流**：告警成立时 `handleRaidEvent` 会按巡检周期反复进入，
每轮都跑 ncnn 推理是无意义开销。视觉只用于提高置信，不承担实时性职责。

## 三、⚠️ 本轮修掉的一处"我自己引入的隐患"

给 `BgeEmbedder` 加 `release()`（低内存时释放 ORT 会话）后，出现一条新路径：

```
useBge = true（索引是 512 维）  +  ORT 会话被释放  →  embed() 返回 null
                                                   →  原本退回 64 维哈希向量
```

而 `computeCosineSimilarity` 是按 `minOf(v1.size, v2.size)` 截断比较的 ——
等于拿 64 维哈希向量去比 512 维索引的前 64 维，得到**完全无意义**的相似度。
表现为"检索出了结果，但结果和查询毫无关系"，**比没有结果更危险，因为它看起来是正常工作了**。

修法：该场景返回**与索引同维的零向量**，余弦恒为 0，检索退化为"无语义信号"（安全且可解释）。

## 四、资源冗余分析

| 项目 | 现状 |
|------|------|
| 加载准入 | `ResourceGuard.canAfford(costMb)`：加载后仍需保留 **120MB** 安全余量；系统可用内存 < **220MB** 直接拒绝 |
| 读不到水位时 | **按"不允许加载"处理**（保守），而不是放行 |
| 已纳管的重资产 | YOLO（预算 24MB）、bge/ORT（预算 40MB） |
| 系统回收联动 | `ComponentCallbacks2.onTrimMemory` ≥ `TRIM_MEMORY_RUNNING_CRITICAL` 时回调全部释放钩子 |
| 降级链是否闭环 | YOLO 不可用 → 走现有 OpenCV/几何路径；bge 不可用 → 64 维哈希（**且已修好维度错配**）；均不抛异常 |

**为什么不做"内存不够就停掉一切"**：那会造成更糟后果（压秒到一半被自己停掉）。
本设计只做**准入判断**与**可观测性**，不做激进自杀。

| 模块 | 工具是否就绪 | 你侧要做 |

| rbt3 意图+槽位 | `tools/p1/train_intent_slot.py` ✅ | 合成数据 → 微调 → 导出 ONNX INT8 |

### 🔶 建议引入（低成本，需你确认后我再落地）

| 模块 | 价值 | 代价 |
|------|------|------|
| **R8/ProGuard keep 规则** | 开启 `minifyEnabled` 后可显著减包并做代码混淆 | 需为 JNI 符号、`Parcelable`、JSON 序列化补 keep 规则；否则会崩 |
| **JNI 层 `CheckJNI`/符号自检** | 空桩与真引擎在运行时难以区分 | 小 |
| **日志导出（本地文件）** | 用户报障时一键导出 | 小；注意**只落本地，不上网** |

### ❌ 明确不建议引入

| 候选 | 不引入的理由 |
|------|-------------|
| 崩溃/遥测**联网上报** | 与项目"100% 端侧、0 云端 Token 依赖"的定位直接冲突；且引入隐私合规负担 |
| 推送 / 账号体系 | 已有卡密授权（`LicenseGate`），再引入是重复建设 |
| 多 ABI 打包 | 原生库按 3~4 份重复打包，APK 体积会翻倍以上（见 `docs/07` 的 60MB 分析） |
| 通用大模型端侧运行时 | 现有 `EdgeSlmEngine` 是正则实现（其 KDoc 已诚实声明）；引入 GGUF/MNN 会带来数十 MB 与不确定的推理质量，当前 ROI 不成立 |
